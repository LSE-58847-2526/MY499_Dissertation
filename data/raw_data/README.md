# Raw data

Place the raw TSJE files here. Scripts `01`–`02` expect exactly these file names:

- `08.-Padron-particip-abstenc-mesa-1996-a-2023-actualizado.csv`
- `candidatos-1998-a-2023-municipales-y-generales.csv`

Source: Electoral Justice of Paraguay (TSJE). Files are semicolon-separated and
encoded in Latin1.
