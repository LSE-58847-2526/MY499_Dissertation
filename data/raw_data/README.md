# Raw data

Scripts `01`–`02` expect these two files in this folder:

- `08.-Padron-particip-abstenc-mesa-1996-a-2023-actualizado.csv`
- `candidatos-1998-a-2023-municipales-y-generales.csv`

Source: Electoral Justice of Paraguay (TSJE). Files are semicolon-separated and
encoded in Latin1.

The electoral register file (`08.-Padron-...`) is too large for GitHub and is
archived on Zenodo instead:

**https://doi.org/10.5281/zenodo.21896946**

Download it from Zenodo and place it in this folder before running `01`–`02`.
