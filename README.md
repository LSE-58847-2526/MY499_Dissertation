# Seeing Themselves on the Ballot

Replication data and R code for the MSc dissertation *"Seeing themselves on the
ballot: Young candidates and youth turnout after an electoral reform in 
Paraguay"* (MY499, MSc in Social Research Methods, Department of Methodology,
London School of Economics and Political Science).

## Overview

This project studies whether the relationship between the supply of young
municipal council candidates and youth turnout changed after Paraguay's 2019
electoral reform (Law No. 6318/2019), which let voters cast preferential votes for individual candidates.

Using district-level electoral records, it compares the pre-reform (2015) 
and post-reform (2021) municipal elections, with placebo checks on a 
pre-reform window (2006–2010) and the mayoral contest. 

*Note: the code in this repository is provided for transparency and
reproducibility.*

## Data

All primary data come from public administrative sources. There are no human
participants and no personal survey data.

| Input | Location | Source |
|-------|----------|--------|
| Electoral register / participation / abstention (1996–2023) | [Zenodo](https://doi.org/10.5281/zenodo.21896946) | Electoral Justice of Paraguay (TSJE) |
| Candidates, municipal and general elections (1998–2023) | `data/raw_data/` | Electoral Justice of Paraguay (TSJE) |
| TSJE response letter (documents the age request) | `data/auxiliary/` | Formal request to the TSJE (Appendix B) |
| District boundaries shapefile | `data/maps/` | National Institute of Statistics of Paraguay (INE) |

Full definitions of every variable in the three datasets are documented in
`output/Codebook.xlsx`.

The processed datasets in `output/` are included, in order for scripts `03` to `05` 
to be run without the raw inputs. To reproduce the full pipeline, place
the raw files listed above in the corresponding folders (each folder contains a
short note with the exact expected file name).

The raw electoral register file exceeds GitHub's size limit of 25MB and is
archived on Zenodo: **https://doi.org/10.5281/zenodo.21896946**. Download it 
and place it in `data/raw_data/` before running scripts `01` and `02`.

## Reproducing the analysis

The scripts use the [`here`](https://here.r-lib.org/) package for paths, so the
project runs from its root folder regardless of the machine. Open the folder as
the working directory (an RStudio Project is convenient) and run the scripts in
order:

```r
source("scripts/01_load_data.R")   # loaded automatically by 02
source("scripts/02_clean_data.R")  # writes the datasets in output/
source("scripts/03_descriptives.R")
source("scripts/04_analysis.R")
source("scripts/05_maps.R")
```

Scripts `03`–`05` read the datasets in `output/`, so they can be run directly
using the included files without re-running `01`–`02`.
